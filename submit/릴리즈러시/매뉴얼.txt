========================================================
  릴리즈 러시 (RELEASE RUSH) · 매뉴얼
========================================================
※ 게임 화면과 규칙은 「게임설명서.pdf」에 그림으로 정리되어 있습니다.

■ 게임 소개
  신입 개발자가 되어 기획 → 개발 → 테스트 → 최종 보스를 지나
  60초 안에 서비스를 출시하는 아케이드 게임. 한 판 약 3분, 쉬지 않고 몰아칩니다.
  - 층마다 미니게임 6종 중 하나가 무작위
  - 미스 1회 = 제한 시간 −2초, 0초가 되면 종료
  - 빨리 깰수록 남은 시간이 큰 점수로 바뀜
  - 남은 시간이 조여 옴: 30초 HURRY → 15초 DANGER(붉은 테두리) → 5초 카운트다운
  - 콤보: 10콤보부터 콤보마다 「N COMBO!」가 점점 커짐 (NICE → ... → LEGENDARY)
  - 피버: 아무 키나 연타, 끝나면 연타 10회당 +1콤보

■ 실행 방법 (설치 · 인터넷 필요 없음)
  ZIP 압축 풀기 → 「게임실행.html」 더블클릭 → F11 전체 화면
  → Enter → 닉네임 입력 → Enter → 룰 카드(누를 키 · 방법 한 줄)를 보고 Space
  - Microsoft Edge 또는 Chrome에서 열립니다.
    다른 프로그램으로 열리면: 오른쪽 클릭 → 연결 프로그램 → Microsoft Edge
  - 소리는 첫 키 입력 뒤부터. M 키로 켜기/끄기

■ 조작 방법
  시작 · 다음 ......... Space / Enter (클릭 가능)
  고르기 .............. 1 2 3 또는 ←→ + Enter (클릭 가능)
  일시정지 · 소리 ..... Esc · M
  배포 타이밍 ......... Space (초록 구간에서)
  커맨드 입력 ......... 방향키 순서대로 (빨간 화살표는 반대 방향)
  장애 알림 ........... Space (초록불에만, 노란불은 함정)
  코드 리뷰 분류 ...... ← 버그 / → 정상
  컴파일 차지 ......... Space 꾹 → 초록 구간에서 떼기
  알림 두더지 ......... ← ↓ → 알림 칸 (대표님 메시지는 누르지 않기)
  피버 · 그로기 ....... 미니게임 자리에 피버 패널이 뜨면 아무 키나 연타
                         (끝나면 연타 10회당 +1콤보, 「다시 시작!」 뒤 미니게임 계속)
  ※ 방향키 대신 WASD 가능. 각 미니게임은 룰 카드에서 시범 플레이로 보여 줍니다.

■ 랭킹 확인 방법
  - 대기 화면 오른쪽: 전체 TOP 10
  - 결과 화면: 등급 · 점수 · 이번 순위 · TOP 5
  - 기록은 이 PC 브라우저에 저장되어 껐다 켜도 유지
    (같은 PC · 같은 브라우저 · 같은 파일 위치 기준)
  - 기록 초기화(운영자): 대기 화면에서 R 키 3초 안에 5번 → 확인

■ 참고
  - 남은 시간 15초 이하에서 화면이 붉게 깜빡이는 것은 정상 연출입니다.

■ 권장 환경
  Windows 10/11 · Microsoft Edge 또는 Chrome · 16:9 화면 · 키보드
