01한 줄 요약

방향키 커맨드로 프로젝트 공정을 돌파하며, 안전하게 갈지 신기술에 걸지 매 층 선택해서 120초 안에 출시까지 가는 게임.
한 판최대 120초
구성3층 + 보스
조작방향키
확정 카드10종
특수 보상4종
저장localStorage

설계 원칙 (지금까지 정한 것)

익숙한 조작 + 새로운 소재

방향키 커맨드는 누구나 아는 조작입니다. 소재(개발 프로젝트)와 결과 화면으로 차별화합니다.

루트 = 난이도

층마다 안전·위험 루트를 고릅니다. 초보와 고수가 같은 게임에서 각자 맞는 난이도로 플레이합니다.

확정 70 : 운 30

확정 카드가 바닥을, 운 보너스가 천장을 담당합니다. 운이 나빠도 끝까지 갈 수 있습니다.

실패해도 점수는 남음

시간이 끝나도 그때까지의 점수로 랭킹에 오릅니다. 처음 하는 사람도 기록을 남깁니다.

02게임 흐름

보라색 칸은 층마다 반복되는 구간입니다. 보상·루트 선택 화면에서는 타이머가 멈추고, 대신 10초 안에 고르지 않으면 첫 번째 선택지가 자동으로 선택됩니다.

대기 화면 (TOP 10)→ 닉네임 입력→ 시작 카드 1장 선택→ 루트 선택→ 층 플레이 (커맨드)→ 확정 카드 + 보너스 룰렛→ ×3 → 보스: 출시 D-Day→ 결과 · 칭호→ 랭킹
종료 조건

① 보스 클리어(출시 성공) ② 제한 시간 120초 소진 중 먼저 오는 쪽. 어느 경우든 결과 화면에서 기록을 자동 저장하고 랭킹을 보여 줍니다.

03루트 맵과 층 구성

프로젝트 공정 3단계가 층이고, 마지막이 보스입니다. 층마다 두 루트 중 하나를 고르며, 이전 선택과 상관없이 다음 층에서 다시 고를 수 있습니다.

층별 구성

층배경 (정적 도트)화면 속 명령어 예시검증된 방식신기술 도입
1층 · 기획화이트보드 회의실회의 소집, 요구사항 정리, 와이어프레임4칸 × 3개, 변형 없음5칸 × 3개, 버그 화살표 섞임
2층 · 개발모니터 3대 책상git commit, npm install, git merge5칸 × 3개6칸 × 3개, 버그 + 미확인 스펙
3층 · 테스트버그 보드와 포스트잇npm test, 버그 재현, 회귀 테스트5칸 × 4개7칸 × 4개, 변형 비율 높음

검증된 방식 안전 루트

  • 커맨드가 짧고 변형이 없음
  • 점수 배율 ×1, 보너스 확률 20%
  • 빨리 끝나서 시간을 아낄 수 있음

신기술 도입 위험 루트

  • 커맨드가 길고 변형 화살표가 섞임
  • 점수 배율 ×2, 보너스 확률 40%
  • 시간이 더 걸려 보스 도달이 빠듯해짐

04커맨드 입력 규칙

화면에 명령어 이름과 화살표 줄이 나오면 순서대로 입력합니다. 리듬에 맞출 필요는 없고 순서만 맞으면 됩니다.

입력

  • 방향키와 WASD 모두 사용 가능
  • 카드 선택: 1 · 2 · 3 키 또는 마우스 클릭, 루트 선택: ↑ / ↓ 후 Enter
  • 키를 누르고 있어 생기는 반복 입력은 무시
  • 방향키를 눌러도 페이지가 스크롤되지 않게 막음

성공과 실패

  • 맞게 누르면 그 칸에 불이 켜짐
  • 틀리면 그 커맨드만 처음부터 다시 (화면 흔들림 + 빨간 번쩍임). 게임은 계속됨
  • 커맨드를 끝내면 다음 커맨드로. 층의 커맨드를 모두 끝내면 클리어
  • 실수 횟수를 기록해 무결점 보너스에 사용

05보상 — 확정 카드와 운 보너스

층을 클리어하면 확정 카드 3장 중 1장을 고르고, 이어서 보너스 룰렛을 돌립니다. 카드는 숫자만 바꾸는 것과 규칙을 바꾸는 것을 섞었습니다.

확정 카드 10종

입력단축키 등록

모든 커맨드 길이 −1 (최소 3칸). 중복 불가

입력자동 완성

커맨드마다 첫 칸 자동 입력. 2장까지 겹침

실수린터

진행리팩토링

다음 층 커맨드 개수 −1

변형코드 리뷰

06보스 — 출시 D-Day

구조

  • 보스 체력 = 커맨드 5개 (6칸)
  • 커맨드 하나를 끝낼 때마다 체력 1칸 감소
  • 버그·미확인 스펙 화살표가 섞여 나옴

압박

  • 8초마다 장애 발생: 제한 시간 −5초, 화면 빨갛게 번쩍임
  • 보스 진입 때 남은 시간이 화면 중앙에 크게 표시됨

클리어

  • 출시 성공 보너스 +2,000점
  • 남은 시간 1초당 +20점
  • "배포 완료" 연출 후 결과 화면

보스는 새 시스템이 아니라 "길고 어려운 층 + 시간 감소 이벤트"로 만듭니다. 구현 비용을 거의 늘리지 않으면서 마지막 고비를 만들 수 있습니다.

07점수 공식과 칭호

커맨드 성공   = 칸 수 × 10 × 루트 배율
층 클리어      = 300 × 루트 배율
               (무결점 배포 카드 + 실수 0회 → 그 층 점수 ×1.5)
보스 클리어   = 2,000 + 남은 초 × 20
특수 보상      = 투자 유치 +1,000

루트 배율: 검증된 방식 ×1 / 신기술 도입 ×2
시간이 끝나면 그 순간까지의 점수가 최종 점수

예상 점수대 (조정 전 계산값)

  • 안전 루트만, 보스 클리어: 약 3,500 ~ 4,000점
  • 위험 루트 위주, 보스 직전 시간 초과: 약 3,000 ~ 3,500점
  • 위험 루트 위주, 보스 클리어: 약 5,000 ~ 6,000점
  • 1~2층에서 시간 초과: 약 500 ~ 1,500점

목표: 안전하게 끝까지 간 사람과 과감하게 가다 마지막에 못 간 사람이 비슷한 점수. 과감하게 가서 성공한 사람이 최상위.

결과 칭호

조건칭호결과 문구 예시
보스 클리어 + 신기술 도입 3회유니콘 스타트업 CTO"PHANTOM 팀, 신기술로 출시 성공! 남은 시간 12초"
보스 클리어출시 장인"PHANTOM 팀, 서비스 출시 성공!"
보스 도달, 시간 초과배포 직전의 개발자"아깝다! 출시 D-Day에서 멈췄습니다"
3층 도달QA 통과 대기 중"테스트까지 왔습니다. 조금만 더!"
1~2층열정 넘치는 인턴"첫 커밋 완료! 다시 도전해 보세요"

실패 문구도 응원하는 톤으로 씁니다. 채용박람회 방문객이 기분 좋게 자리를 뜨는 게 목표입니다.

08화면 구성 — 플레이 화면 목업

정적 도트 배경 위에 HUD와 커맨드 줄을 올립니다. 내부 해상도 320×180으로 그린 뒤 정수배로 확대해 픽셀이 뭉개지지 않게 합니다.

위쪽 HUD

현재 층·루트, 남은 시간(가장 크게), 점수, 시간 진행 바

가운데

층별 정적 도트 배경. 성공 시 점수 팝업, 실패 시 흔들림만 움직임

아래쪽

명령어 이름 + 진행(2/3) + 화살표 줄. 구경꾼도 볼 수 있게 크게

양옆

왼쪽은 보유 카드, 오른쪽은 다음 보너스 확률

09기술 구현

파일 구성

  • 게임실행.html 하나에 HTML·CSS·JS를 모두 넣음. 더블클릭하면 Edge·Chrome으로 바로 실행
  • 외부 CDN·웹폰트·온라인 이미지 없음. 폰트는 맑은 고딕 + 숫자·화살표는 직접 그림
  • 도트 그림은 코드 안의 픽셀 배열이나 fillRect로 그림 (이미지 파일 없음)
  • 캔버스 320×180을 정수배로 확대, image-rendering: pixelated

기록 저장 (localStorage)

  • 키 하나에 기록 배열을 JSON으로 저장: 닉네임, 점수, 도달 층, 보스 클리어 여부, 루트 기록, 날짜
  • 저장 직후 다시 읽어서 확인, 실패하면 화면에 경고
  • 랭킹: 점수 내림차순 TOP 10, 동점이면 먼저 달성한 기록이 위
  • 같은 닉네임은 최고점만 랭킹에 표시 (전체 기록은 보존)

부스 운영 기능

  • 대기 화면: 아무도 안 할 때 TOP 10과 "Enter로 시작" 표시
  • 마지막 닉네임 기억, Enter 한 번으로 재도전
  • 운영자용 기록 초기화: 대기 화면에서 R 키 5번 + 확인 창
  • F11 전체 화면 안내 문구

주의할 점

  • 기록은 같은 PC·같은 브라우저에서만 이어짐 → 설명서에 명시
  • ES 모듈(type="module") 사용 금지 (더블클릭 실행에서 막힘)
  • 탭 전환이나 창이 내려가면 자동 일시정지
  • 난수는 Math.random으로 충분. 같은 날 같은 순서로 나오게 하는 시드 기능은 나중에 고려

10구현 범위

마감이 하루라서 범위를 세 단계로 나눴습니다. 필수만 끝나도 출품할 수 있게 순서대로 만듭니다.

필수 없으면 출품 불가

  • 닉네임 입력 → 플레이 → 결과 → 랭킹
  • 커맨드 입력, 제한 시간 120초
  • 3층 + 보스, 루트 선택
  • 확정 카드 3장 중 1장 (최소 6종)
  • localStorage 저장·랭킹 TOP 10
  • 설명서 TXT

권장 선정 가능성을 올림

  • 버그·미확인 스펙 화살표
  • 보너스 룰렛 + 특수 보상 4종 + 천장
  • 층별 정적 도트 배경 4장
  • 결과 칭호, 대기 화면
  • 성공·실패 연출 (팝업, 흔들림, 번쩍임)
  • 카드 10종 전부

여유가 있으면

  • 황금 커맨드
  • 효과음 (Web Audio로 생성)
  • 오늘 / 전체 랭킹 탭
  • 운영자 기록 초기화
  • 스노우볼·왕귀 트랙 밸런스 (나중으로 보류한 항목)
