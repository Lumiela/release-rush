# 07. 완성도 · 유불리 평가와 개선안 (v14 기준)

> 방향성을 다시 점검하기 위한 평가 자료입니다. 측정값은 화면 없이 게임 코드를 그대로 돌린 일반인 반응속도 봇 기준이고, **실제 사람 플레이테스트는 아직 없습니다.**
> 점검 시각: 11/10(화) 새벽 3시 40분 · **마감 11/10(화) 17:00 (약 13시간 남음)**

## 1. 한 줄 평가

> **게임으로서는 완성 단계, 제출물로서는 아직 0%.** 기능과 연출은 공모작 중 상위권을 노릴 만하지만, 설명서 · ZIP · 실행 확인이 하나도 안 되어 있고, 처음 하는 사람에게는 화면과 규칙이 많다.

## 2. 공모 요강 충족

| 요강 | 상태 | 근거 |
|---|---|---|
| 3~5분 짧은 플레이 | ✅ | 한 판 실제 2.7~3.3분 (선택 화면 · 룰 카드 읽는 시간 포함) |
| 인터넷 없이 Windows 실행 | ✅ (확인 필요) | HTML 한 파일 172KB, 외부 주소·웹폰트·`fetch` 없음, 글꼴은 Windows 기본 「맑은 고딕」. **더블클릭(file://) 실행은 아직 직접 확인 안 함** |
| 랭킹: 점수 순위 + 로컬 기록 유지 | ✅ | localStorage, TOP 10 (대기 화면) · TOP 5 + 내 순위 (결과창) |
| 닉네임 입력 | ✅ | 1~10자 |
| ZIP + 설명서 (게임 소개 · 실행 · 조작 · 랭킹 확인) | ❌ | 아직 없음 |
| Google Drive 공유 + 구글폼 제출 | ❌ | 아직 안 함 |

## 4. 유리한 점

| 관점 | 내용 |
|---|---|
| 심사 (운영사 검토) | 행사 주제(취업 · 개발 직무)와 소재가 딱 맞음. 한 파일로 바로 실행. 연출과 완성도가 눈에 띔. 등급 · 점수 구성 · 엔딩 로그 등 "끝까지 만든" 느낌 |
| 부스 운영 | 대기 화면 데모가 자동으로 돌아 사람을 끔. 1인 1회 흐름(다시 도전 없음), 방치 안전장치, 랭킹 경쟁 |
| 재방문 · 화제성 | 판마다 미니게임 · 카드가 달라 구경하는 재미, 신기술 복리로 "한 방" 고득점 가능 |
| 발표 · Velog | 개발 과정이 데이터로 남아 있음(봇 측정, 비교 이미지) |

## 6. 개선안

### P0 · 오늘 반드시 (약 1~1.5시간)

1. **설명서 작성**: 게임 소개 · 실행 방법(더블클릭, 권장 브라우저 Edge/Chrome) · 조작 · 랭킹 확인 · 기록 초기화(R 5번) · 주의(같은 브라우저에서 기록 유지)
2. **제출 폴더 정리**: `게임실행.html` + `설명서` (+ 스크린샷). 기획 HTML · docs는 제외
3. **더블클릭 실행 확인**: 탐색기에서 열기 → 한 판 → 창 닫고 다시 열어 랭킹 유지 확인, 와이파이 끈 상태로 Edge · Chrome
4. **기록 초기화 후 ZIP** → Google Drive 업로드 → 시크릿 창에서 링크 확인 → 구글폼 제출

### P1 · 부스 체감이 큰 것 (각 30분~1시간, 고르기)

| 안 | 내용 | 기대 효과 |
|---|---|---|
| A | **시작 카드 선택을 1층 클리어 뒤로** 미루고, 1층은 안전 루트로 바로 시작 | 첫 플레이까지 5단계 → 3단계, 규칙을 한 번 해 본 뒤 카드를 고름 |
| B | **넘기기 줄이기**: 층 정산표는 다 나오면 2초 뒤 자동 진행(Space로 빨리), WARNING 룰 카드는 2층부터 짧게 | 확인 입력 35 → 약 27회 |
| C | **초보 구제**: 보스 체력 180 → 150, 또는 시간 종료 직전 보스면 "연장 5초" 1회 | 초보 클리어율 약 +15%p (추정) |
| D | **효과음** (Web Audio로 코드 안에서 생성, 파일 없음): 성공 · 미스 · 클리어 · 그로기 타격 · 정산 카운트 | 타격감 · 피드백. 오프라인 문제 없음 |
| E | **연타 상한**: 초당 12회까지만 인정 | 키보드 혹사 · 매크로 방지, 점수 차이는 거의 없음 |

### P2 · 시간이 남으면

- 사람 3명 플레이테스트 → 글자 크기 · 설명 문구 · 미니게임 손맛 조정
- 데모 길이 단축(3~4분 → 2분), 대기 화면 회전율
- 기획 HTML(`game-design.html`) 현재 버전으로 갱신 또는 삭제

### 하지 않는 것 (마감까지 범위 고정)

- 새 미니게임 · 새 시스템 추가, 큰 밸런스 개편 (검증 시간 없음)

## 7. 방향성 점검 질문

1. **깊이 vs 즉시성**: 지금은 "전략이 깊은 게임" 쪽. 부스에서는 P1-A · B로 앞부분을 가볍게 하는 게 유리한데, 심사에서 깊이를 보여 주는 쪽을 더 중시할지?
