## 손맛 다음은 구조

층 하나는 재미있어졌다. 남은 건 **한 판**이었다. 매판 같은 순서로 같은 게임을 하면 두 번째 판부터 지루하고, 끝나는 순간이 밋밋하면 다시 할 이유가 없다.

이번 편은 v4에서 v13까지, 한 판의 시작부터 끝을 채운 과정이다.

*그림 1. 처음 늘린 미니게임 4종. 나중에 6종이 된다*

## ① 미니게임을 층보다 많이 만들고, 매판 섞는다

"미니게임을 스테이지보다 많이 만들어서 스테이지마다 랜덤으로 주자"는 제안에서 시작했다.

- 미니게임을 공통 틀(입력 · 업데이트 · 그리기)로 묶고, 판마다 3종을 1 · 2 · 3층에 무작위 배정한다.
- 1 · 2층이 끝나면 **WARNING 중간보스**가 다음 층 미니게임을 강한 패턴으로 8초 동안 먼저 보여 준다. 관문이 아니라 점수 이벤트라 못 해도 괜찮다. 다음 층의 예고편이자 튜토리얼이다.
- **최종 보스**는 그 판의 미니게임 3종을 전부 섞는다.

## ② 카드는 문장이 아니라 숫자로

카드 선택에 10초 제한이 있었고, 효과가 "판정 30% 완화" 같은 문장이었다. 고민할 틈도, 계산할 방법도 없었다.

시간 제한을 없애고 **효과를 숫자로** 바꿨다. 야근 수당 "작업 점수 ×1.25", 커피 한 잔 "제한 시간 +10초"처럼. 화면 아래에는 지금 빌드의 배율을 모아 보여 준다.

![그림 3](IMG-03-05)
*그림 3. 설명형 카드와 10초 자동 선택(왼쪽) → 수치형 카드와 현재 빌드(오른쪽)*

같은 숙련자 봇인데 카드 조합에 따라 점수가 **약 1만 3천 ~ 3만 4천**으로 벌어졌다. 전략이 점수를 바꾼다는 뜻이다.

## ③ 운이 끼어드는 자리: 아이템 · 코인 · 상점

운과 선택의 재미를 늘리려고 아이템 14종, 코인, 그리고 아이템을 얻는 자리 네 곳을 만들었다. WARNING 보상, 뒤집힌 랜덤 카드, 일반 상점, 대박 상점. 모든 선택 화면에 **확률과 가격을 공개**했다.

![그림 4](IMG-03-06)
*그림 4. 아이템 이벤트 4종*

확률은 2만 번씩 뽑아서 설정값과 ±0.5%p 안에서 맞는지 확인했다. 가격과 효과는 이때 추정치로 두었고, 이 "남는 코인"은 다음 편에서 문제가 된다.

## ④ 규칙을 모른 채 시작하지 않게

스테이지가 안내 1.5초 뒤 저절로 시작돼서, 규칙을 모른 채 시간이 흐르는 경우가 있었다. 그래서 모든 스테이지 앞에 **룰 카드**를 두고, Space를 눌러야 시작하게 했다.

![그림 5](IMG-03-07)
*그림 5. 자동 시작 배너(왼쪽) → 룰 카드 + Space로 시작(오른쪽)*

"스테이지가 넘어가는 조건이 안 보인다"는 피드백도 받았다. 진단해 보니 미스해도 잃는 게 보이지 않아서 긴장감이 없었다. 화면 위에 남은 작업(■■□□)을 항상 띄우고, **미스 1회 = 제한 시간 −2초**를 넣었다.

## ⑤ "끝났다"는 느낌 만들기

끝나는 순간도 손봤다. 처음엔 클리어하면 바로 결과 화면이었고, 결과 화면은 시작 화면과 배경까지 같았다.

| 순서 | 장면 | 하는 일 |
| --- | --- | --- |
| 1 | **CLEAR 도장 + 정산표** | 남은 시간이 점수로 바뀌는 과정을 한 줄씩 보여 준다 |
| 2 | **출시 컷신 3초** | 성공은 SERVICE OPEN과 박수, 실패는 72%에서 멈춘 DEPLOY FAILED |
| 3 | **엔딩 로그** | 이번 판에 고른 카드 · 아이템 · 루트가 한 줄씩. 성공은 RELEASE NOTE, 실패는 INCIDENT REPORT |
| 4 | **결과창** | 등급 도장 · 점수 · 순위 · TOP 5. 성공은 새벽 도시, 실패는 비 오는 사무실 |

## ⑥ 보스를 보스답게

보스전도 결국 "작업 8개를 순서대로"라 층과 다를 게 없었다. 체력 바를 붙이고, **미니게임 4개 성공 → 그로기 → 연타로 체력 깎기**를 반복하게 바꿨다. 패턴, 빈틈, 몰아치기.

![그림 9](IMG-03-12)
*그림 9. 커맨드 8개(왼쪽)에서 체력 바 + 그로기 연타(오른쪽)로*

체력 90은 초보 클리어 33%로 너무 어려워 60으로 시작했다. 이 숫자는 이후 180, 그리고 신기술을 고를 때마다 2배까지 간다.

## ⑦ 미니게임은 6종이 됐다

마지막으로 지금까지 없던 조작 두 가지를 더했다. Space를 꾹 눌렀다가 초록 구간에서 떼는 **컴파일 차지**, 알림이 뜬 칸의 방향키를 누르는 **알림 두더지**(👑 대표님 메시지는 끄면 미스).

## 정리: 지금의 한 판

| 단계 | 내용 |
| --- | --- |
| 시작 | 대기 화면 → 닉네임 → 미니게임 6종 중 3종을 층에 배정 |
| 1층 | 룰 카드 → 미니게임 → 정산표 → 시작 카드 |
| 사이 | WARNING(다음 층 예고) → 보상 아이템 → 보너스 스테이지 · 룰렛 · 상점 → 루트 선택 |
| 2 · 3층 | 같은 흐름, 루트에 따라 난이도와 점수 배율이 다름 |
| 보스 | 체력 바 · 미니게임 4개 → 그로기 연타 반복 |
| 끝 | 출시 컷신 → 엔딩 로그 → 결과 · 랭킹 |

구조를 만들고 나니 숫자가 문제였다. 루트를 바꿔도 결과가 비슷하고, 코인은 남아돌고, 어떤 판은 늦게 깰수록 점수가 높았다. 다음 편은 **봇으로 밸런스를 잡은 이야기**다.

> **한 판의 끝을 설계해야 다음 판이 생긴다.** 결과 화면이 시작 화면과 같으면, 사람은 끝났다는 걸 모른다.
