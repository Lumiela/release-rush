========================================================
  릴리즈 러시 (RELEASE RUSH) · 게임 설명서
========================================================

■ 게임 소개
--------------------------------------------------------
신입 개발자가 되어 업무 몬스터를 쓰러뜨리며
기획 → 개발 → 테스트를 지나 제한 시간 65초 안에
서비스를 "출시"하는 짧은 아케이드 게임입니다. (한 판 약 3분)

- 층마다 미니게임 6종 중 하나가 무작위로 나옵니다.
  배포 타이밍 · 커맨드 입력 · 장애 알림 · 코드 리뷰 분류 · 컴파일 차지 · 알림 두더지
- 층 사이에는 다음 층을 미리 맛보는 WARNING 중간보스,
  마지막에는 체력 바가 있는 최종 보스 「출시 D-Day」가 기다립니다.
- 카드 · 아이템 · 상점 · 룰렛으로 판마다 다른 전략을 세우고,
  "신기술 도입" 루트를 고를수록 더 어렵지만 점수가 크게 오릅니다.
- 미스하면 제한 시간이 2초 줄어듭니다. 시간이 0초가 되면 게임 종료.


■ 실행 방법 (인터넷 필요 없음)
--------------------------------------------------------
1. ZIP 파일의 압축을 풉니다.
2. 「게임실행.html」을 더블클릭합니다.
   - Microsoft Edge 또는 Chrome에서 열립니다. (Windows 기본 Edge 권장)
   - 다른 프로그램으로 열리면: 파일 오른쪽 클릭 → 연결 프로그램 → Microsoft Edge
3. 전체 화면으로 하려면 F11 을 누르세요.
4. 대기 화면에서 Enter(또는 클릭) → 닉네임 입력 → Enter 로 시작합니다.

※ 설치 · 인터넷 연결이 필요 없는 HTML 파일 하나로 된 게임입니다.
※ 소리는 첫 키 입력 뒤부터 납니다. M 키로 켜고 끌 수 있습니다.


■ 조작 방법
--------------------------------------------------------
[공통]
  Space / Enter ........ 시작, 다음으로 넘기기
  Esc .................. 일시정지
  M .................... 소리 켜기 / 끄기
  숫자키 1·2·3, ←→ ..... 카드 · 아이템 · 루트 고르기 (마우스 클릭도 가능)

[미니게임] 스테이지마다 시작 전에 룰 카드로 조작을 알려 줍니다.
  배포 타이밍 .......... 커서가 초록 구간에 오면 Space (클릭 가능)
  커맨드 입력 .......... 화면의 화살표 순서대로 방향키 (WASD 가능)
                          빨간 화살표는 반대 방향, ? 는 차례가 되면 공개
  장애 알림 ............ 신호가 초록불로 바뀌는 순간 Space (노란불은 함정)
  코드 리뷰 분류 ....... 버그 카드면 ← , 정상 카드면 →
  컴파일 차지 .......... Space를 꾹 누르고, 게이지가 초록 구간에 오면 손을 뗌
  알림 두더지 .......... 알림이 뜬 칸의 방향키 ← ↓ → (대표님 메시지는 누르지 않기)

[피버 · 보스 그로기]
  아무 키나 연타 ....... 피버 타임 점수, 최종 보스 체력 깎기


■ 랭킹 확인 방법
--------------------------------------------------------
- 대기 화면 오른쪽: 전체 TOP 10 (닉네임별 최고 점수)
- 한 판이 끝난 뒤 결과 화면: 이번 점수의 순위, TOP 5, 등급(S~D), 점수 구성
- 기록은 이 PC의 브라우저에 저장되어 게임을 껐다 켜도 유지됩니다.
  (같은 PC · 같은 브라우저 · 같은 파일 위치에서 유지됩니다.
   시크릿 창이나 다른 브라우저에서 열면 기록이 따로 저장됩니다.)
- 기록 초기화(운영자용): 대기 화면에서 R 키를 3초 안에 5번 → 확인


■ 한 판의 흐름
--------------------------------------------------------
닉네임 → 1층 → (시작 카드) → WARNING → 아이템 → 보상 카드 · 룰렛 · 상점
→ 2층 → WARNING → … → 3층 → 최종 보스(미니게임 4개 → 그로기 연타 반복)
→ 출시 컷신 → 엔딩(이번 판 기록) → 결과 · 랭킹 → 다음 사람


■ 제작 정보
--------------------------------------------------------
- 제작: 1인
- 형식: HTML · CSS · JavaScript 한 파일 (외부 라이브러리 · 인터넷 연결 없음)
- 그림 · 효과음 · 배경 음악: 모두 코드로 직접 그리고 합성 (외부 음원 · 이미지 파일 없음)
- 권장 환경: Windows 10/11, Microsoft Edge 또는 Chrome, 16:9 화면, 키보드
